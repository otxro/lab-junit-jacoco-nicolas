# Pasta lib/

Aqui fica **um único arquivo**, que traz o JUnit 5 completo (API, motor, testes
parametrizados e o executor de linha de comando):

    junit-platform-console-standalone-1.11.4.jar

Se o arquivo **não estiver aqui** (por exemplo, o repositório foi baixado sem ele), baixe
na raiz da pasta `lib/` com um dos comandos abaixo, ou abra o endereço no navegador e
salve o arquivo dentro de `lib/`:

    https://repo1.maven.org/maven2/org/junit/platform/junit-platform-console-standalone/1.11.4/junit-platform-console-standalone-1.11.4.jar

- Linux / macOS:  `curl -L -o lib/junit-platform-console-standalone-1.11.4.jar <endereço acima>`
- Windows (PowerShell):  `Invoke-WebRequest <endereço acima> -OutFile lib\junit-platform-console-standalone-1.11.4.jar`
